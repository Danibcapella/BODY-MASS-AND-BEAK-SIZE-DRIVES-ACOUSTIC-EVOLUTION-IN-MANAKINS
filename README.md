Supplementary material for the paper "Body mass and beak size drives acoustic evolution in Manakins.
Figures shown in the paper are available here in .pdf format, as well as the tables in .xlsx format.
The file "Analysis.R" contains the script for all the statistical and exploratory analysis conducted in the paper.
The file "Spectrogram.R" contains the script for generating the spectrograms used for ilustrating the methods.
The file "Data_Pipridae.xlsx" contains all the raw data collected for the analysis, as well as two other tabs which were exported as .csv files for the analysis present in the script
